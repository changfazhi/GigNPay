- POST /v2/checkout/orders  body { intent: "AUTHORIZE", purchase_units: [{ reference_id, custom_id, invoice_id, description, amount: { currency_code: "USD", value } }], payment_source: { paypal: { experience_context: { return_url, cancel_url, user_action: "PAY_NOW" } } } } -> 201 { id, status: "PAYER_ACTION_REQUIRED", links: [{ rel: "payer-action" | "approve", href }] }

- POST /v2/payments/authorizations/{id}/capture  body { amount, final_capture, invoice_id }
