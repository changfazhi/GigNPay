## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-11-01 | Information disclosure | Diagnostics endpoint | high | mitigate | 404 when `DIAG_TOKEN` unset; session required (401); `x-diag-token` compared with `timingSafeEqual` (403); output has no env values, connection strings or tokens; live checks for 401/403 |
| T-01-11-02 | Denial of service | SSE connection exhaustion | medium | mitigate | Session required; `ConnectionCap(3)` per user (429); one shared LISTEN client per process; abort/cancel cleanup releases intervals and caps |
| T-01-11-03 | Elevation of privilege | DDL from the diag route | low | mitigate | Only three fixed extension names; every CREATE inside a transaction that always rolls back; no user input reaches SQL |
| T-01-11-04 | Tampering | Shell injection via binary probes | low | mitigate | `execFile` with fixed arguments, no shell, 5 s timeout |
