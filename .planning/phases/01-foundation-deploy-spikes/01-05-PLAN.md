## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05-01 | Elevation of privilege | Sign-up body `role` | high | mitigate | `hooks.before` allowlist in `options.ts`; unit tests reject admin/unknown/missing roles |
| T-01-05-02 | Elevation of privilege | update-user changing role | high | mitigate | `databaseHooks.user.update.before` throws FORBIDDEN; unit test |
| T-01-05-03 | Elevation of privilege | Self-registration as judge (D-02) | high | mitigate | Judge allowed only when `DEMO_MODE === "true"` or header code matches `JUDGE_SIGNUP_CODE` via SHA-256 + `timingSafeEqual`; code never stored; unit tests for each branch |
| T-01-05-04 | Spoofing | Password guessing on sign-in | medium | mitigate | Better Auth scrypt hashing, min 8 chars, `customRules` 10 per 60 s on sign-in/sign-up in production |
| T-01-05-05 | Spoofing | Cross-site auth requests | medium | mitigate | Better Auth origin checks with `trustedOrigins: [appOrigin()]` |
</threat_model>
