## Phase Goal

**As a** solo builder presenting Pay-When-Done, **I want to** run the app on a public Render HTTPS URL with role-based accounts, private photo and video storage and written results for every risky vendor behaviour, **so that** the money and evidence code in later phases is built on verified ground.

**This plan's slice (Walking Skeleton, part 5 of 7):** a background worker process proves it is alive by writing to Postgres every minute, and anyone (and Render's health check) can read how long ago it was seen at `/api/health`.

<objective>
Build the heartbeat module test-first, the pg-boss worker entry point that writes heartbeats, and the `/api/health` endpoint that reports database and worker status plus the deployed commit.

Purpose: this is the thinnest path that proves web, worker and Postgres share one codebase and one database. Plan 01-09's dashboard shows the worker status from this module; plan 01-10 uses `/api/health` as Render's health check and as the deploy wait signal.
Output: `src/server/heartbeat.ts` (+ test), `worker/index.ts`, `src/app/api/health/route.ts`.
</objective>
