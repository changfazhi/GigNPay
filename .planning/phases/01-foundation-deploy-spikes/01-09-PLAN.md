## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> pages and /api/me | Session cookie decides what data is shown |
| browser -> /api/auth/sign-up/email | Judge code typed in the browser |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-09-01 | Elevation of privilege | /dashboard and /api/me without a session | medium | mitigate | `getActor()` in the page and route; redirect to /login or 401; `proxy.ts` is only an optimistic redirect |
| T-01-09-02 | Information disclosure | /api/me returning other users | medium | mitigate | Returns only the session user's own fields; no id parameter accepted |
| T-01-09-03 | Spoofing | Judge code entered in the browser | low | mitigate | Code is sent only as the `x-judge-signup-code` header to the same origin and checked server-side (plan 01-05) |
</threat_model>
