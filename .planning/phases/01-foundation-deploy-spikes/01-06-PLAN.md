## Phase Goal

**As a** solo builder presenting Pay-When-Done, **I want to** run the app on a public Render HTTPS URL with role-based accounts, private photo and video storage and written results for every risky vendor behaviour, **so that** the money and evidence code in later phases is built on verified ground.

**This plan's slice (Track B, laptop-only spike S-LLM):** the owner can read, in one result file, whether Claude and Gemini both return schema-valid scores for the same photos, how fast, how much they cost and how far apart they land.

<objective>
Run spike S-LLM: score the same four JPEGs with Claude and Gemini in parallel, three runs each, using one Zod rubric, re-validate every output, and write the S-LLM result fragment with the six SPIKES.md headings.

Purpose: Phase 5's dual-model verifier depends on both vendors returning comparable structured scores; this spike records the real model ids, failure modes and score gaps before any verification code is written.
Output: `scripts/spikes/llm/*`, `spike-evidence/s-llm/{fixtures.json,runs.json,RESULT.md}`.
</objective>
