## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-12-01 | Spoofing | Forged webhook | high | mitigate | Postback verification with the resolved webhook id; fail closed on missing headers or unknown id; unverified deliveries return 401 and never act; forged POST tested live |
| T-01-12-02 | Tampering | Re-serialised body breaks or bypasses verification | medium | mitigate | `req.text()` first; `buildVerifyBody` embeds raw text verbatim; unit test with odd spacing and key order |
| T-01-12-03 | Repudiation | Replayed or duplicated events | medium | mitigate | `paypal_event_id` primary key with a deliveries counter; replay dedupe proven live in plan 01-14 |
| T-01-12-04 | Denial of service | Large or flooding unverified posts | medium | mitigate | 256 KB cap -> 413; unverified bodies truncated to 16 KB; unverified rows keyed by transmission id so real event ids cannot be squatted |
| T-01-12-05 | Information disclosure | Logging bodies or tokens | medium | mitigate | One log line with key, type, verified, reason, debug id; token never logged; evidence passes `check-evidence` |
</threat_model>
